# Golang File Manager

File manager app written on Go for Ubuntu Server 24 (LTS)

Prerequisites:
1. Default entry folder set in .env `HOME_DIR`
2. Add API for read directories, file info
3. Add web admin with default user & password: admin:admin or in .env `ADMIN`, `PASSWORD`
4. Web UI: By first release read only mode: Read directories & files
5. Light & Dark theme
6. Prepare Makefile for build app for Linux
